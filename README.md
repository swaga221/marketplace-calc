# Калькулятор юнит-экономики WB · Ozon · Я.Маркет

Считает реальную чистую прибыль с одной продажи на Wildberries, Ozon и Яндекс.Маркете с учётом комиссий, эквайринга, логистики, упаковки, хранения, рекламы, возвратов и налога. Подсказывает безубыточную цену и рекомендуемую цену под целевую маржу.

**Live preview (временный):** https://trusted-ai-persona-app-gpshw3gw.devinapps.com

## Возможности

- 3 маркетплейса (WB / Ozon / Я.Маркет), 3 схемы доставки (FBO / FBS / DBS), 15 категорий с пресетами комиссий
- 8 видов затрат: закупка, комиссия, эквайринг, логистика, упаковка, хранение, реклама, возвраты
- 5 налоговых режимов: НПД 4 %, НПД 6 %, УСН 6 %, УСН 15 %, без налога
- Безубыточная цена + рекомендуемая цена под целевую маржу (0–80 % с явным «недостижимо», если цифры физически не сходятся)
- Метрики: чистая прибыль, маржа %, ROI, прибыль с партии
- Кнопка «Поделиться» — копирует URL со всеми введёнными значениями
- Кнопка «Скачать PNG» — экспорт результирующей панели картинкой
- Тёмная тема (системная по умолчанию + ручной переключатель)
- Авто-сохранение всех значений в `localStorage`
- Sticky-плашка с KPI снизу на мобильных
- Баннеры предупреждений: «сделка в убыток» и «маржа < 8 %»
- FAQ-секция на 8 вопросов
- Подсказки (`title`) на всех инпутах
- SEO/мета-теги, кастомный favicon, OG-картинка

## Стек

- [Vite 6](https://vitejs.dev/) + [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
- [Lucide React](https://lucide.dev/) — иконки
- [html-to-image](https://github.com/bubkoo/html-to-image) — экспорт PNG

Серверная часть не нужна: все расчёты происходят в браузере.

## Локальная разработка

```bash
npm install        # установить зависимости
npm run dev        # запустить dev-сервер на http://localhost:5173
npm run lint       # ESLint
npm run build      # production-сборка в ./dist
npm run preview    # локально посмотреть прод-сборку
```

## Деплой

Готовый билд (`dist/`) — это статика, разворачивается на любом бесплатном хостинге:

- **Cloudflare Pages** — рекомендуемый вариант (Framework preset: Vite, Build command: `npm run build`, Output dir: `dist`).
- **Vercel** / **Netlify** — работает «из коробки», конфиг не нужен.
- **GitHub Pages** — тоже подходит, но без удобного CI/CD из коробки.
